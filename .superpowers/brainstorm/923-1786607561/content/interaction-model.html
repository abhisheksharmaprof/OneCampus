What kind of "drag and drop" do you have in mind?

All three let you drag things around visually and insert placeholders/tables by dragging — they differ in how free the layout is. This matters because invoices/receipts still have to print cleanly on A4 paper.

Free canvas

Drag anything anywhere on the page, resize freely, stack elements, pixel-level control. Most powerful, but easiest to accidentally break print layout (overlapping text, content running off the page) and the most work to build well.

Structured zones

The page has fixed zones (header / items table / totals / footer). Within each zone you drag to reorder blocks, drag placeholder tokens onto fields or table columns, and drag to add/remove/reorder table columns. Layout always stays print-safe. Less "anything goes," but hard to break.

Grid canvas

Middle ground: free positioning like option A, but elements snap to an invisible grid and to each other's edges, with guardrails against elements overlapping or running off the printable page. More freedom than B, safer than A.
